Task construction · what I optimize for

A task is only as good as its reward.

  • Verifiable, not judged: programmatic graders (hash · tabular · geometric · visual · behavioral) — no hand labels, no LLM-judge drift in the reward signal.
  • Hard to hack: graders check the artifact and the trace; checks keep them trustworthy as models get stronger.
  • Long-horizon by design: real expert workflows (hours of work), computer-use included — the regime where post-training has headroom.
  • Trajectory analysis closes the loop: we run frontier models (OpenAI, Anthropic, Meta TBD, Qwen, Seed) and report failure modes back — I know where tasks break models and where models break tasks.

Equile · founded Apr 2026

Agent infra, built from zero.

  • One session API, many harnesses: Claude Code, Codex, Cursor, custom Docker — same contract for workspace FS, tool/MCP I/O.
  • Isolation that scales: per-session sandboxes with multi-tenant packing (>20× per-agent compute reduction); auth never in images or CLI args.
  • Snapshot pause/resume and background scheduling: atomic claims, lease reclaim — agents scheduled like model inference.
  • Why it matters here: an RL rollout fleet is the same problem — thousands of isolated environments, reproducible resets, live monitoring, nothing leaking between runs.
